# RVJ-Bank-Management-System
Browser-based Bank Management System using HTML, CSS and JavaScript
## Features

- Separate User and Admin menus.
- View customer account details.
- Add and delete bank accounts.
- Update customer name, email, and phone number.
- Create and manage loan records.
- Check loan status and identify loan defaulters.
- Input validation for account management.
- Browser-based data storage using LocalStorage.
- Responsive interface with light and dark theme support.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage

## How to Run

1. Clone or download this repository.
2. Open `index.html` in a web browser.
3. Select the User or Admin menu to explore the application.

## Note

This is an educational demonstration project. It uses browser LocalStorage and client-side demo access controls. It is not intended for real banking operations or secure storage of financial information.
